### What's working

- **`terraphim-agent update`** and **`terraphim-grep update`** — end-to-end over R2, no GitHub credentials, no rate limiting. Manifest fetch → asset download → Ed25519 signature verification → atomic-rename install.
- **`check-update`** — sub-second manifest fetch from `downloads.terraphim.ai` (Cloudflare edge-cached).
- **GitHub fallback** — transparent fallback on R2 transport failure; uses fixed repo (`terraphim-clients` not `terraphim-ai`) + `GITHUB_TOKEN` forwarding (no 403).
- **Archive signing** — release workflow signs every `.tar.gz` with zipsign Ed25519; multi-key verifier supports rotation; unsigned archives hard-rejected.
- **Self-update** — installs to `current_exe()` parent (fixes `~/.cargo/bin` shadowing); atomic-rename replaces running binary (fixes ETXTBSY).
- **CI health** — hourly `r2-manifest-health` workflow fetches every manifest + HEADs every asset URL.
- **Release pipeline** — `release-binaries.yml` bumps version before build, signs with `ZIPSIGN_PRIVATE_KEY`, uploads to R2 via wrangler with manifest last, curl fail-closed.
- **Live manifests** — `terraphim-agent` 1.21.9, `terraphim-grep` 1.21.9, `terraphim-cli` 1.21.9 all serving 200.

### What's deferred

- **MissingSignature→reject flip** — shipped (commit `3a146ad`). Unsigned archives are now hard-rejected.
- **Durable R2 CI token** — the `CLOUDFLARE_API_TOKEN` secret is a durable Cloudflare API token (`cfat_`, 53 chars, from `op://Terraphim/terraphim.r2.admin.token/password`). Fully scoped for R2 Read+Write on `terraphim-releases`.

### Open / follow-ups

- **Q1 (grep subcommand)** — resolved: `terraphim-grep check-update` / `update` re-added via shared `terraphim_update` crate.
- **Next key rotation** — when needed, append a new public key to `EMBEDDED_PUBLIC_KEYS` in `signature.rs`, add the private half to 1Password + CI secret, ship one signed release. See `adr/ADR-001.md` for the runbook.

### Known bugs fixed in validation

1. **ETXTBSY** — `install_verified_archive` overwrote the running binary in-place. Fixed: stage-to-tempdir + atomic-rename.
2. **zipsign filename context** — archive downloaded to random `NamedTempFile` (.tmpXbSpz) → filename context mismatch → `NoMatch` rejection. Fixed: download to `tempdir()/original-asset-name.tar.gz`.
3. **Wrong repo default** — `repo_name = "terraphim-ai"` in UpdaterConfig; releases live on `terraphim-clients`. Fixed.
4. **No auth token forwarded** — GitHub fallback never called `builder.auth_token()`. Fixed.
5. **Install-path shadowing** — updates to `/usr/local/bin` masked by `~/.cargo/bin`. Fixed: prefer `current_exe()` parent.
6. **Unsigned archives misreported** — `verify_archive_signature` treated ALL unsigned/non-archive input as `Invalid`. Fixed: `FindDataStartAndLen` → `MissingSignature`; `NoMatch` → `Invalid`.
7. **zipsign CLI/library version mismatch** — CLI 0.2.0 vs library 0.2.1 produced incompatible signatures. Fixed: `cargo install zipsign --version 0.2.1`.
