# Documentation

Documentation is the part of a change a future reader needs and the code cannot say: why this
shape, what was rejected, which invariant must hold, what the operator should do when it pages at
3am. A comment restating the next line is not documentation; a comment explaining a non-obvious
constraint is.

The review question is not "is there documentation" but "could someone else operate and change
this without asking the author".

synonyms:: documentation, docs, comments, code comments, readme, docstring, inline comment, runbook, adr, changelog
